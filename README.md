# Расписание на печать

Программа берёт расписание на альбомном листе A4 (`.docx` или `.pdf`), поворачивает его на 90° и ставит в верхнюю часть книжного листа A4. Внизу остаётся свободное место, граница отмечена пунктиром для отреза.

![Иконка](assets/icon.ico)

## Версии для Windows

Обе собираются скриптом `build.ps1` в папку `dist`:

| Файл | Что это |
| --- | --- |
| `RaspisaniePrint-Setup-<версия>.exe` | Установщик. Ставит программу без прав администратора, создаёт ярлык в меню Пуск. Может добавить пункт «Подготовить к печати» в меню файлов `.docx` и `.pdf`. |
| `RaspisaniePrint-portable-<версия>.zip` | Без установки: распакуйте архив в любую папку (можно на флешку) и запустите `RaspisaniePrint.exe`. |

С версии 2.0 окно сделано на Qt (PySide6), а не на tkinter: при изменении размера окно не тормозит, тёмная тема Windows подхватывается сама, файл можно перетащить прямо в окно.

Нужна Windows 10 или 11 (64 бит). Для файлов Word (`.docx`, `.doc`, `.rtf`, `.odt`) нужен установленный Microsoft Word. PDF открывается без Word.

## Как пользоваться

1. Запустите программу и нажмите «Выбрать файл» (или Ctrl+O), либо перетащите файл в окно.
2. Справа появится предпросмотр листа. Настройте поворот и высоту таблицы.
3. Нажмите «Сохранить PDF» (или Ctrl+S). PDF появится рядом с исходным файлом с припиской `_печать`.
4. В окне печати выберите «Реальный размер» или «Без масштабирования».

Подробно: [docs/user-guide.md](docs/user-guide.md).

## Командная строка

```bash
python raspisanie_print.py "Расписание.docx"
```

```bash
python raspisanie_print.py "Расписание.pdf" -o "печать.pdf" --scale 0.9 --rotate 90 --page 2
```

| Параметр | Что делает | По умолчанию |
| --- | --- | --- |
| `-o`, `--output` | Куда сохранить PDF | рядом с исходным, `<имя>_печать.pdf` |
| `--scale` | Доля высоты листа под таблицу, от 0 до 1 | `0.78` |
| `--rotate` | `270` по часовой, `90` против часовой, `0` без поворота | `270` |
| `--page` | Номер страницы, с 1 | `1` |
| `--version` | Показать версию | |

Код выхода: `0` успех, `1` ошибка во входных данных (текст ошибки в stderr), `2` неверные аргументы.
