# Расписание на печать 2.0: окно на Qt (PySide6) вместо tkinter

Дата: 2026-09-19. Предыдущая версия 1.0.0 (tkinter).

## Зачем

Окно на tkinter тормозило при изменении размера, а предпросмотр перерисовывался только через 120 мс после остановки мыши, и до этого место под листом было пустым. Qt рисует окно одним буфером.

## Что не меняется

`raspisanie_core.py` (конвертация, раскладка, рендер PNG), консольный `raspisanie_print.py`, формат и место настроек (`%APPDATA%\RaspisaniePrint\settings.json`), все настройки и горячие клавиши (Ctrl+O, Ctrl+S).

## Окно (`raspisanie_gui.py`)

- Слева: «Исходный файл» (поле пути + «Выбрать файл… (Ctrl+O)»), «Настройки» (страница N из M, поворот: три переключателя, высота таблицы: ползунок 30–100 % + подпись, «Сбросить настройки»), «Сохранить как» (путь + «Изменить…» + «Открыть PDF после сохранения»), кнопка «Сохранить PDF (Ctrl+S)», подсказка про «Реальный размер».
- Справа: `Preview` — лист с тенью. Картинка листа рендерится `core.render_png` под текущую высоту. При ресайзе уже готовая картинка сразу масштабируется (плавно), а чёткая перерисовывается через 120 мс после последнего изменения.
- Снизу: строка статуса (красная при ошибке) и бегущий индикатор, пока файл загружается.
- Новое: файл можно перетащить в окно.
- Загрузка файла (Word конвертирует до минуты) — в отдельном потоке; результат через очередь, окно забирает его таймером Qt. Пока грузится, кнопки «Выбрать» и «Сохранить» выключены, закрытие спрашивает подтверждение.
- Все сообщения идут через `dialogs` (info / error / warning / yes_no / open_path / save_path) — тесты их подменяют.
- Тема: стиль windows11, Qt сам следует за светлой/тёмной темой Windows. Русские тексты стандартных кнопок Qt.

## Сборка

`.venv` в проекте. `build.ps1`: создать `.venv` при необходимости, поставить `requirements-dev.txt`, тесты, PyInstaller `--onedir` (без tkinter и лишних модулей Qt, без `opengl32sw.dll` и чужих переводов), portable = zip с папкой программы, установщик Inno Setup (при обновлении удаляет старую `_internal`). Версия 2.0.0.

## Тесты

Тесты ядра не меняются. Тесты окна переписаны на pytest-qt. Инварианты:

1. Пока идёт загрузка, «Выбрать» и «Сохранить» выключены; после любого исхода (успех, ошибка) включены, индикатор скрыт.
2. После ошибки загрузки программа остаётся рабочей, предыдущий загруженный файл остаётся открытым (старый закрывается только при успешной загрузке нового, как и в 1.0).
3. Статус красный только пока есть ошибка; исправленная страница возвращает обычный статус.
4. Сохранение поверх исходного файла отклоняется, исходник не меняется.
5. Настройки на диске всегда проходят `clean_settings` без изменений (записываются только корректные значения).
6. Предпросмотр по высоте вписан в область и по пропорциям равен книжному A4.
7. Случайные последовательности действий (страница, поворот, масштаб, ресайз, сохранение) не роняют окно и не оставляют его в состоянии «грузится».
