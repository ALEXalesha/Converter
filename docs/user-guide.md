# Руководство пользователя

## Установка

Установщик `RaspisaniePrint-Setup-<версия>.exe` не просит прав администратора. По умолчанию программа ставится в папку пользователя. На шаге «Дополнительные задачи» можно отметить:

- ярлык на рабочем столе;
- пункт «Подготовить к печати» в меню файлов `.docx` и `.pdf` (правый клик по файлу в Проводнике). В Windows 11 он находится в разделе «Показать дополнительные параметры».

Удаление: «Параметры - Приложения - Расписание на печать - Удалить». Пункт меню Проводника удаляется вместе с программой.

Портативная версия `RaspisaniePrint-portable-<версия>.exe` запускается сразу, без установки.

## Окно программы

Слева настройки, справа предпросмотр листа A4 в том виде, в каком он уйдёт в PDF.

| Настройка | Что делает |
| --- | --- |
| Исходный файл | Файл расписания: `.pdf`, `.docx`, `.docm`, `.doc`, `.rtf`, `.odt`. |
| Страница | Какую страницу документа печатать. Рядом написано, сколько их всего. |
| Поворот таблицы | «По часовой стрелке» подходит для обычного альбомного расписания. «Против часовой», если таблица встала вверх ногами. «Без поворота» для книжного исходника. |
| Высота таблицы на листе | Сколько процентов высоты листа занимает таблица, от 30 до 100. По умолчанию 78. Ниже рисуется пунктир. |
| Сбросить настройки | Вернуть 78 % и поворот по часовой. |
| Сохранить как | Путь к PDF. По умолчанию рядом с исходным файлом, имя с припиской `_печать`. |
| Открыть PDF после сохранения | Сразу открыть готовый файл в программе для PDF. |

Горячие клавиши: Ctrl+O открыть файл, Ctrl+S сохранить PDF.

Файл можно открыть и так: перетащите его на значок программы или на ярлык. Или выберите «Подготовить к печати» в меню файла, если включили этот пункт при установке.

Программа запоминает поворот, высоту, галочку «Открыть после сохранения», последнюю папку, а с 2.1.0 и размер и место окна, в том числе развёрнутое. Они хранятся в `%APPDATA%\RaspisaniePrint\settings.json`. Если файл настроек испорчен, программа просто берёт значения по умолчанию.

## Печать

Откройте готовый PDF и в окне печати выберите «Реальный размер» или «Без масштабирования» (в некоторых программах «100 %»). Если выбрать «По размеру страницы», принтер может чуть уменьшить лист, и пунктир сдвинется.

## Файлы Word

Для `.docx` и других файлов Word программа запускает свою, невидимую копию Word и сохраняет документ в PDF. Это занимает от нескольких секунд до минуты. Открытые у вас документы Word она не трогает, и исходный файл не меняет. Файл может быть открыт у вас в Word во время конвертации.

## Если что-то пошло не так

| Сообщение | Что делать |
| --- | --- |
| Нет доступа к ... Возможно, файл открыт в другой программе | Закройте готовый PDF в программе просмотра и сохраните ещё раз. Старый файл при этом не портится. |
| Выходной файл совпадает с исходным | Выберите другое имя в поле «Сохранить как». Программа не перезаписывает исходник. |
| PDF защищён паролем | Откройте PDF, сохраните копию без пароля и выберите её. |
| Файл повреждён или это не PDF | Файл битый или у него неправильное расширение. |
| Не удалось запустить Microsoft Word | Word не установлен. Сохраните расписание в PDF на другом компьютере или откройте PDF-версию. |
| Word не смог открыть или сконвертировать файл | Документ защищён паролем или повреждён. Откройте его в Word и сохраните обычной копией. |
| Страницы N нет | В документе меньше страниц, чем указано. |

Если закрыть программу во время конвертации Word, она спросит подтверждение. Скрытый процесс Word в этом случае может остаться, его можно завершить в Диспетчере задач (`WINWORD.EXE`).
