# Проверка на баги: гипотезы и инварианты

Проверка шла в три шага:

1. Пробный скрипт подал старому коду плохие входные данные.
2. Каждая найденная проблема стала тестом, потом её исправили.
3. Property-тесты (hypothesis) проверили инварианты на тысячах случайных входов: разные размеры страниц, свой `/Rotate` у страницы, масштаб, поворот, номер страницы, имена файлов, испорченные настройки.

## Найденные баги

Номер - это порядок, в котором баг нашёлся. «Где» - как именно он был найден.

| # | Гипотеза | Что было | Где | Исправление |
| --- | --- | --- | --- | --- |
| 1 | Масштаб больше 1 или `nan` | Принимался молча, таблица вылезала за лист | пробный скрипт | `check_options`: только `0 < scale <= 1`, конечное число |
| 2 | Масштаб 0 или меньше | Трассировка `ValueError: rect must be finite` | пробный скрипт | та же проверка, понятное сообщение |
| 3 | Страница -1 | Молча бралась последняя страница | пробный скрипт | `check_page`: только `0 <= page < page_count` |
| 4 | Страница больше, чем есть | Трассировка `IndexError` | пробный скрипт | то же |
| 5 | Выходной файл = исходный | mupdf падал с `Permission denied` | пробный скрипт | `check_output`, в том числе при другом регистре букв |
| 6 | Готовый PDF открыт в программе просмотра | Падение, мог остаться полузаписанный файл | пробный скрипт | запись во временный файл и `os.replace`, старый файл цел, понятное сообщение |

## Проверенные инварианты

Для любого допустимого входа:

- на выходе ровно одна страница, книжный A4 (595.28 x 841.89 пт);
- содержимое не выходит за лист и за верхнюю часть высотой `scale` от листа (допуск 0.5 пт);
- пропорции страницы сохранены, с учётом поворота и её собственного `/Rotate`;
- содержимое вписано: касается боков листа или верхней и нижней границы области;
- содержимое по центру области;
- текст исходной страницы есть на выходе, и это текст нужной страницы;
- исходный документ не меняется (содержимое, размер, поворот каждой страницы);
- две сборки с одинаковыми параметрами дают одинаковую картинку;
- поворот 270 - текст идёт сверху вниз, 90 - снизу вверх, 0 - слева направо.

Для любого недопустимого входа (плохой масштаб, поворот, номер страницы) - только `PrintPrepError`, никаких других исключений и никаких записанных файлов.

Для файлов:

- путь по умолчанию никогда не совпадает с исходным и лежит в той же папке;
- `same_path` совпадает с тем, что говорит сама файловая система, в том числе для `ı` и `I` (Windows считает их разными файлами);
- PDF сохраняется под любым юникодным именем, временных файлов в папке не остаётся;
- исходный файл не блокируется после загрузки и не меняется (проверка по SHA-256).

Для настроек окна: из любого JSON (мусор, `NaN`, `false` вместо поворота, списки, пустой файл) получаются допустимые настройки. `False` отдельно отсекается, потому что `False == 0` и иначе прошёл бы как поворот 0.

## Окно на Qt (версия 2.0)

После каждого шага теста окна проверяется `assert_consistent`:

- кнопки «Выбрать» и «Сохранить» включены тогда и только тогда, когда файл не грузится; индикатор виден только во время загрузки;
- статус красный тогда и только тогда, когда есть ошибка;
- диапазон страницы 1..N, где N - число страниц открытого файла, подпись «из N» совпадает;
- подпись масштаба совпадает с ползунком, поворот всегда допустимый;
- настройки на диске уже чистые: `clean_settings` их не меняет.

Отдельные гипотезы: во время загрузки Ctrl+S, выбор файла и перетаскивание ничего не делают и не показывают сообщений; старый документ закрывается при открытии нового и при закрытии окна; файл, догрузившийся после закрытия окна, тоже закрывается; ошибка загрузки оставляет прежний файл; перетаскивание принимает только один файл расписания.

Мутационная проверка: в `raspisanie_gui.py` по одному вносились 20 ошибок (не выключать кнопки, не закрывать документ, сохранять во время загрузки, принимать любой файл, неверные пропорции листа и т. д.). Тесты ловят 19. Оставшаяся («бросок файла во время загрузки») не меняет поведения: `open_path` сам игнорирует вызов, пока идёт загрузка.

Проверка собранных файлов:

- приложение из portable-архива запускается с PDF в командной строке и не падает;
- установщик ставит программу тихо (`/VERYSILENT /CURRENTUSER`), создаёт ярлык в Пуске и пункт меню Проводника;
- удаление убирает программу, ярлык и пункт меню.
